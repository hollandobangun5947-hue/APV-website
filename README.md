# APV website

Statische, mobielvriendelijke website voor de Amsterdamse Pleit Vereniging. GitHub Pages kan deze website gratis publiceren.

## Publiceren
Upload `index.html` naar de hoofdmap van je GitHub-repository. Kies Settings > Pages > Deploy from a branch > main > /(root).

## Aanpassen
- De evenementen staan onderaan `index.html` in de JavaScript-lijst `events`.
- De kleuren staan bovenaan in CSS onder `:root`.
- Controleer de status van evenementen voordat je ze als bevestigd presenteert.
- Voeg pas een echt ledenformulier toe via een privacyvriendelijke, beveiligde dienst. GitHub Pages ondersteunt zelf geen PHP of database.
- Voeg later het officiële APV-logo, Instagram-link en geaccordeerde bestuursfoto's toe.
