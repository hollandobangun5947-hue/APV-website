# APV-website

Eenvoudige Nederlandstalige statische verenigingswebsite. Alle HTML, CSS en JavaScript staan in `index.html`.

## Lokaal bekijken
Open `index.html` in je browser.

## Publiceren via GitHub Pages
1. Maak een openbare GitHub-repository, bijvoorbeeld `apv-website`.
2. Upload `index.html` naar de hoofdmap van de repository.
3. Ga naar Settings → Pages → Build and deployment.
4. Kies Deploy from a branch, branch `main`, map `/ (root)` en klik Save.
5. De website verschijnt op `https://GEBRUIKERSNAAM.github.io/apv-website/`.

## Aanpassen
Vervang de tijdelijke teksten, bestuurssamenstelling en activiteiten. Voeg pas echte contact- of ledenformulieren toe als de verwerking van persoonsgegevens veilig is ingericht.

## Kosten
GitHub Pages is gratis voor publieke repositories volgens de toepasselijke voorwaarden. Een eigen domeinnaam is optioneel en wordt apart aangeschaft.
